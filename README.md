# Solo Leveling — сборка мини-аппа

Здесь лежит **только собранная игра** — то, что отдаётся браузеру.
Исходники, документация и история разработки живут в отдельном закрытом
репозитории и сюда не попадают.

Репозиторий публичный по одной причине: GitHub Pages на бесплатном тарифе
раздаёт сайт только из публичного репозитория, а Телеграм пускает мини-апп
только по `https`.

Обновляется целиком, одной командой из основного проекта. Править файлы
здесь руками бессмысленно — следующая сборка их перезапишет.
